# Training log

A phone-first gym tracker: Monday cardio, then four lifting days that alternate heavy strength days and lighter hypertrophy days.

## Put it online with GitHub Pages
1. Upload every file in this folder to the root of the repository.
2. In the repository go to **Settings → Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Install it on your phone
- **iPhone (Safari):** Share → Add to Home Screen.
- **Android (Chrome):** menu → Install app.

## Your data
Sessions are saved in the browser on each device, not in this repository.
Use **History → Download backup** now and then, and **Restore backup** to move your log to another phone or laptop.

## Updating the site
After changing `index.html`, bump `VERSION` in `sw.js` so phones pick up the new version.
